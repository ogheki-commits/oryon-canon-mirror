# Archives canon

Ce dossier conserve les anciennes couches ayant servi à construire `canon-current.json`.

- `canon-layers/canon-overrides-v1.2.json`
- `canon-layers/canon-audit-v1.3.json`
- `canon-layers/canon-additions-v1.4.json`

Ces fichiers sont conservés avec leurs blobs d’origine afin qu’aucune information ne soit perdue. Ils ne font plus partie de l’ordre de lecture normal et ne doivent être consultés que pour vérifier une provenance ou récupérer un détail ancien éventuellement omis dans la consolidation.

Pour le travail courant, utiliser :
1. `../ai-context.txt`
2. `../canon-current.json`
3. `../api/lore` ou `../api/lore.json` uniquement si nécessaire.
